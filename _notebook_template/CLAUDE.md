# ノートブック（NotebookLM 風）

このフォルダは「資料を根拠に答える」ためのノートブック。

## 構成
- `sources/`：元の資料（がったが入れる。Claude は中身を書き換えない）
- `sources_text/`：`python3 convert.py` で作るテキスト版（検索・引用に使う）
- `INDEX.md`：資料の一覧と1行要約（Claude が管理）
- `notes/`：Q&A・要約・FAQ などの成果物（Claude が保存）

## セッションの始め方
1. `sources/` に `sources_text/` 未変換の資料があれば `python3 convert.py` を実行する
2. 新しい資料があれば `INDEX.md` に追記する（資料名／種類／1行要約／追加日）
3. 文字が取り出せない資料（スキャン PDF・画像）は、元ファイルを直接読んで確認する

## 回答のルール
- **資料に書いてあることだけを根拠に答える**。一般知識で補うときは「（資料外）」と明記する
- **出典を必ず付ける**：`[ファイル名 p.12]`、`[ファイル名 スライド5]`、`[ファイル名 シート「売上」]`
- 資料に答えがなければ「資料には書かれていない」と答える。推測で埋めない
- 資料同士で食い違いがあれば、両方を出典つきで示す
- 残す価値のある回答・要約は `notes/` に保存してコミットする（ファイル名例: `2026-09-24_競合比較.md`）

## 注意
- 社外秘・顧客名・実名が入った資料は入れない（リポジトリ直下の CLAUDE.md のルール）
- GitHub の上限で 1ファイル100MB まで。大きい資料は分割するか、必要な部分だけ入れる
