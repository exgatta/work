# 差分コピー USB ツール

ネットワークフォルダに毎日追加されるファイルのうち、**まだコピーしていないものだけ**を USB メモリへコピーするツール。
USB メモリの中に入れて、ソフトのインストールなしに Windows 標準の PowerShell だけで動く。

## 仕組み（要点）
- USB 内の `_state\copied.csv` に「コピー済みファイルの一覧（相対パス・サイズ・更新日時）」を記録する。
- 実行時にコピー元を走査し、一覧に無いファイルだけを `data\<実行日>\` 以下へコピーする（フォルダ構造は維持）。
- USB からファイルを別 PC へ移して USB を空にしても、一覧が残っていれば差分判定できる。
- コピーに失敗したファイルは一覧に書かないので、次回実行時に自動で再試行する。
- 更新から 60 秒以内のファイルは「書き込み中」とみなして次回に回す（設定で変更可）。

## ファイル構成
| ファイル | 役割 |
|---|---|
| `差分コピー実行.bat` | **毎日これをダブルクリック**。差分をコピーする |
| `差分コピー_確認のみ.bat` | 何がコピーされるかを表示するだけ。コピーも記録もしない |
| `初回登録_現状をコピー済みにする.bat` | 初回だけ使う。今あるファイルを全部「コピー済み」にして、翌日から差分だけ拾う |
| `差分コピー実行_代替起動.bat` | 通常の .bat が実行ポリシーのエラーで止まる場合だけ使う |
| `DiffCopy.ps1` | 本体（PowerShell 5.1 対応） |
| `config.json` | 設定（コピー元パスなど） |
| `_state\copied.csv` | コピー済み一覧（自動生成。**消すと全件が新規扱いになる**） |
| `logs\` | 実行ログ（90 日で自動削除） |

## 初期設定（1 回だけ）
1. このフォルダごと USB メモリにコピーする（例: `E:\差分コピー\`）。
2. `config.json` をメモ帳で開き、`SourcePath` をコピー元のネットワークフォルダに書き換える。
   `\` は 2 つ重ねる。例: `"SourcePath": "\\\\fileserver\\共有\\日次データ"`
   保存時の文字コードは UTF-8 のまま。
3. エクスプローラーで一度そのネットワークフォルダを開き、アクセスできることを確認する（認証が必要な場合はここで済ませる）。
4. `差分コピー_確認のみ.bat` を実行し、コピー元が読めて対象件数が出ることを確認する。
5. 過去分が不要なら `初回登録_現状をコピー済みにする.bat` を実行する。過去分も欲しければ、そのまま `差分コピー実行.bat` を実行する（全件コピーになるので容量に注意）。

### 特定の USB だけに限定したい場合
実行ログに `ボリュームシリアル: XXXX-XXXX` が表示される。その値を `config.json` の `AllowedVolumeSerial` に書くと、別の USB からは起動しなくなる。

## 毎日の運用
1. 対象 PC に USB を挿す。
2. `差分コピー実行.bat` をダブルクリック。
3. 画面に「コピー成功: N 件」と保存先が出たら完了。`[NG]` と出たら `logs\` の最新ログを見る。
4. `data\<日付>\` の中身を別 PC へ移す（USB 側は消してよい。`_state` と `logs` は消さない）。

## 設定項目（config.json）
| 項目 | 既定値 | 意味 |
|---|---|---|
| `SourcePath` | （必須） | コピー元フォルダ |
| `DestSubFolder` | `data` | コピー先（USB 内の相対パス。絶対パスも可） |
| `RunFolderFormat` | `yyyy-MM-dd` | 実行日フォルダの書式。空文字で日付フォルダなし |
| `Recurse` | `true` | サブフォルダも対象にする |
| `IncludeFileNames` | `["*"]` | 対象ファイル名パターン |
| `ExcludeFileNames` | `~$*, Thumbs.db, desktop.ini, *.tmp` | 除外ファイル名パターン |
| `ExcludeFolders` | `[]` | 除外フォルダ名パターン |
| `SkipIfModifiedWithinSec` | `60` | 更新直後のファイルを見送る秒数。`0` で無効 |
| `CopyUpdatedFiles` | `false` | `true` でコピー済みでも中身が変わったファイルを再コピー |
| `RequireRemovableDrive` | `true` | USB 以外から起動したら中断 |
| `AllowedVolumeSerial` | `""` | 許可する USB のシリアル。空で照合なし |
| `FreeSpaceMarginMB` | `200` | コピー後に残す最低空き容量（MB） |
| `LogKeepDays` | `90` | ログ保持日数 |

## 困ったとき
| 症状 | 対処 |
|---|---|
| 「このシステムではスクリプトの実行が無効」「実行ポリシー」のエラー | `差分コピー実行_代替起動.bat` を使う |
| 「コピー元フォルダにアクセスできません」 | エクスプローラーで同じパスが開けるか確認。開けない場合はネットワーク・権限の問題 |
| 「リムーバブルドライブではありません」 | USB 上の .bat から起動しているか確認。検証目的なら `RequireRemovableDrive` を `false` |
| 「空き容量が足りません」 | `data\` 内の移動済みファイルを削除する |
| 「書き込み中の可能性があるため今回は見送り」 | 異常ではない。数分後にもう一度実行すればコピーされる |
| 同じファイルがもう一度コピーされる | `_state\copied.csv` が消えた・壊れた可能性。`copied.csv.bak`（直前の実行時のコピー）を `copied.csv` に戻す |
| 全部やり直したい | `_state` フォルダを削除してから `初回登録_現状をコピー済みにする.bat` |

## 制限事項
- 元で削除されたファイルは何もしない（削除の反映はしない）。
- パスが 260 文字を超えるファイルは Windows の制限でコピーに失敗することがある（ログに「失敗」と出る）。
- 「新規」の判定はファイルの相対パスで行う。同じ名前で上書きされたファイルは既定では対象外（`CopyUpdatedFiles` で変更可）。

## 検証状況
- PowerShell 7.4（Linux）で、初回登録 → 差分コピー → 再実行 0 件 → 失敗ファイルの次回再試行 → 更新検知 → 代替起動、を確認済み。
- Windows PowerShell 5.1 での実機確認は未実施。5.1 で動く文法だけで書いているが、初回は `差分コピー_確認のみ.bat` から試すこと。
